# Logotipo

No hemos recibido ningún archivo de logotipo, así que la web lleva un distintivo
provisional dibujado en SVG: el cono dentro del aro del pozzetto. Aparece en la
cabecera, en el pie, en el cargador y en el favicon.

## Cómo poner el vuestro

Dejad el archivo aquí con el nombre exacto:

```
assets/logo/logo.svg
```

La web lo detecta al cargar y sustituye el provisional en todos los sitios a la vez,
sin tocar código. Requisitos:

- **SVG** con el trazo en `currentColor` o en blanco, sobre fondo transparente.
- Área de seguridad **cuadrada** (el hueco de la cabecera es un cuadrado de 34-44 px).
- Si el logotipo es horizontal (símbolo + texto), pasadnos también la versión sólo símbolo:
  la cabecera y el pie ya llevan el texto "La Gelateria / Italiana · Madrid" al lado.

El favicon (`assets/logo/favicon.svg`) hay que sustituirlo a mano cuando llegue el
logotipo definitivo.
